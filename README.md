# 3D Printing Portfolio

Original, self-designed 3D-printable projects — a working record as I learn CAD (mostly OpenSCAD, some FreeCAD/Blender) from scratch on a Bambu Lab A1 mini.

The goal here is breadth: varied projects across mechanical, organic, and parametric design, rather than one narrow specialty. OpenSCAD in particular doubles as an intro to programmatic/parametric thinking I'm using to teach my son — designing for manufacture and construction the way you'd design software.

## Status

Just getting started — printer's been running store-bought/community models while I ramp up on CAD fundamentals. Projects will land here as they're actually designed, not before.
