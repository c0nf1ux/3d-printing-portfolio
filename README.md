# 3D Printing Portfolio

Original, self-designed 3D-printable projects: a working record as I
learn CAD (mostly OpenSCAD, some FreeCAD/Blender) from scratch on a Bambu
Lab A1 mini.

The goal here is breadth. Varied projects across mechanical, organic, and
parametric design, rather than one narrow specialty. OpenSCAD in
particular doubles as an intro to programmatic/parametric thinking I'm
using to teach my son, designing for manufacture and construction the way
you'd design software.

## Status

Just getting started. Printer's been running store-bought/community
models while I ramp up on CAD fundamentals. Projects will land here as
they're actually designed, not before.

## Related

- [versus-chess](https://github.com/c0nf1ux/versus-chess): a larger
  standalone parametric OpenSCAD project (chess set sizing rig + themed
  piece sets), split into its own repo since it has its own license terms
  and is meant for community forking.
- [a1-mini-painting-station](https://github.com/c0nf1ux/a1-mini-painting-station):
  modular painting-supply organizer sized specifically for the A1 mini's
  180mm bed, six connector-compatible modules across separate plates.
- [bambu-print-tools](https://github.com/c0nf1ux/bambu-print-tools): the
  printer automation and mesh-sanity-check toolkit that grew out of
  building the painting station (deliberately not an MCP server, see its
  `DECISIONS.md` for why), now shared across projects here instead of
  copy-pasted per repo.

## Licensing

No blanket license yet. Terms will be set per-project as designs land
here, since some may end up sold (e.g. on Printables/MakerWorld/Etsy) and
shouldn't be pre-committed to an open license that would undercut that.
Check each project's own folder for its specific terms.
